# Atelier OAuth 2.0 et OpenID Connect

Application de gestion des demandes sécurisée avec :

- Keycloak : authentification et gestion des rôles.
- Spring Boot : API REST sécurisée avec Spring Security.
- React : interface utilisateur.
- OAuth 2.0 / OpenID Connect : authentification avec PKCE.
- JWT : protection des API.

## Utilisateurs

- Alice : USER
- Bob : USER, ADMIN

## Architecture

- Keycloak : localhost:8080
- Spring Boot : localhost:8081
- React : localhost:5173
